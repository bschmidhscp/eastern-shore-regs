# § 144-68. Statutory authorization.

Pursuant to the authority contained in Md. Code Ann., Alcoholic Beverages and Cannabis § 1-322, there is hereby established a Dorchester County Community Reinvestment and Repair Fund for the purposes set forth in this article.
