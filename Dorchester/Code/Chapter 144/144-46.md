# § 144-46. Rates of reduction.

*[Amended 4-4-2017 by Bill No. 2017-2 ]*

Except for 1) the operating personal property of a public utility and 2) personal property used to generate electricity for sale, the assessment of personal property is subject to County property tax on:


| Percentage of Value of Personal Property | For the Taxable Year Beginning |
|---|---|
| 90% | July 1, 2006 |
| 80% | July 1, 2007 |
| 70% | July 1, 2008 |
| 60% | July 1, 2009 |
| 50% | July 1, 2010 |
| 40% | July 1, 2011 |
| 30% | July 1, 2012 |
| 20% | July 1, 2013 |
| 10% | July 1, 2014 |
| 0% of its value for the taxable year beginning | July 1, 2015, and for each taxable year thereafter |
