# § 65-2. Definitions.

*[Amended 6-4-2024 by Bill No. 2024-5 ]*

As used in this chapter, the following words have the meanings indicated:

**ICC** The organization known as the International Code Council.

**INTERNATIONAL BUILDING CODE (IBC)**

A. The 2021 Edition or current edition of the International Building Code issued by the ICC.

B. Includes interim amendments or subsequent printings of the current edition of the International Building Code issued by the ICC.

**INTERNATIONAL RESIDENTIAL CODE (IRC)**

A. The 2021 Edition or current edition of the International Residential Code issued by the ICC.

B. Includes interim and amendments or subsequent printings of the 2003 Edition or current edition of the International Residential Code issued by the ICC.
