# § 95-3. Persons required to file statements.

All persons holding, and candidates for the following, county offices are required to file the statements provided for in this chapter:

A. County Commissioners.

B. County Treasurer.

C. Such other nonelected public officials. appointed by the County Commissioners, as the County Commissioners may deem required to file by a subsequent ordinance or resolution.
