# § 175-108. Loading space requirements.

When required, off-street loading spaces of a sufficient size and number shall be provided on the same lot for each separate occupancy requiring delivery of goods. Determination of sufficiency shall be made as part of a site plan review or, if no site plan is required, by the Zoning Administrator.
