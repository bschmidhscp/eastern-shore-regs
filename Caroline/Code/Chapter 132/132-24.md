# § 132-24. Condemnation authority.

If the Code Official finds that a premises contains an unsafe structure, unsafe equipment, or a structure unfit for human occupancy or use, then he/she may order the structure or part of it to be placarded, vacated and closed, or the equipment to be placarded and placed out of service. If the Code Official finds that repair or modification of the structure is not feasible, then the Code Official may, after consultation with the County Attorney, order the structure to be demolished, razed and removed.
