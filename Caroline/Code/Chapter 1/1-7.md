# § 1-7. Miscellaneous provisions.

A. When terms in the Code are not defined, they shall have their ordinarily accepted meanings such as the context may imply.

B. Masculine pronouns include feminine pronouns.

C. Any section or any part of any section of this Code that is legally determined to be unconstitutional, void or ineffective for any cause shall not be deemed to affect the validity or constitutionality of any other section or part of the Code.
