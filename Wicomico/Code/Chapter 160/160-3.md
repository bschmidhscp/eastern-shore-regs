# § 160-3. Incorporation of standards.

A. This Code shall, by reference, incorporate the following Codes as guidelines for corrective action:

  (1) Chapter 117, incorporating the International Residential Code and the International Building Code.

  (2) Wicomico County Plumbing Code.[1]

> Note: [1] Editor's Note: See Ch. 183 , Plumbing.

  (3) National Electric Code.

B. Nothing herein shall be construed to supersede, modify or set aside any provisions of the County's Zoning Code.
