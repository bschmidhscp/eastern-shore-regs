# § 225-135. Number of spaces required.

A. In the case of any building, structure or premises, the use of which is not specifically mentioned in this Part 10, the provisions for any similar use, as determined by the Zoning Administrator, shall apply.

B. When determination of the number of parking spaces required results in a requirement fractional space, any fraction shall be counted as one parking space.

C. Unless otherwise specified elsewhere in this chapter, parking requirements according to use shall be as shown in the following table:
