# § 1-14. Charter revisions.

A. County Charter. The adoption of this ordinance and the Code shall be deemed to include the County Charter without changes of any nature having been made to same.

B. Municipal Charters. The adoption of this ordinance and the Code shall be deemed to include the Charters of the various municipalities in the county without any substantive revision of any nature having been made to same, except for the renumbering of the Charters. The adoption of this ordinance and the Code shall be deemed to include the renumbering of the Municipal Charters.
