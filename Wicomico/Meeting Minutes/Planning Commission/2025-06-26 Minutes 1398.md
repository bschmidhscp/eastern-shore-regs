DISCUSSION - Tidal Health Garage - Interpretation of accessory use as it applies to the hospital and the
building height. (B. Jackson)

Ms. Jackson and Mr. Parker appeared before the Commission to interpret the code. The Code

<!-- page 10 -->
SW Planning Commission — Minutes — June 26, 2025
Page 10

suggests that the zone Hospital and Hospital Accessory structures are prescribed a different maximum
height than all other permitted uses in the zone. The Code lacks definitions for the terms ‘Accessory
Structure’ and ‘Hospital Structure’. Ms. Jackson suggested that, typically, Accessory Structures are on
the lot as a permitted use, but the proposed garage (for hospital use only) is not on the parcel. Staff
recommends considering the parking garage as a hospital accessory structure and not limiting hospital
accessory structures to the same parcel as the hospital, which would severely limit the growth of the
hospital and be inconsistent with the purpose of the Hospital District.

Mr. Drew inquired whether the parking structure would ever be converted into a different type
of structure, which would cause the existing height to not comply with the code. Mr. Parker confirmed
the parking structure would remain a parking structure.

Chairman Dashiell expressed a preference for having the code amended to be clear rather
than open to interpretation. Mr. Parker was not opposed to doing a text amendment.

Ms. Laura Ryan, legal counsel to the City, stated that if the Planning Commission was not inclined
to do a text amendment, the Planning Commission could make a finding as part of the plan approval
process that a hospital accessory structure does not need to be on the same lot if it is part of the same
overall project.

The Commission declined to render an interpretation, preferring to make a finding as part of a
plan approval or a text amendment to the code.
