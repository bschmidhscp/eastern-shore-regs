# § 192-9. Application of other standards.

This Part 1 is not intended to supersede any state laws pursuant to the Annotated Code of Maryland as follows:

A. State fire laws, Article 38A.

B. State elevator laws, Article 89.

C. State boiler laws, Article 48.
