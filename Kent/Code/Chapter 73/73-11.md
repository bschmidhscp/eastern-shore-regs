# § 73-11. Prohibited acts.

A. It shall be unlawful for any person, firm or corporation to erect, place, construct, alter, extend, remove, demolish, use or occupy any building or structure or equipment regulated by this code or cause the same to be done in conflict with or in violation of any of the provisions of this code.

B. It shall be a violation of this chapter to interfere with the Building Code Administrator or any other building code enforcement officer in the performance of his/her duties.
