# § 49-11. Conforming changes.

Whenever in the Code of Public Local Laws of Kent County, or in any rule or regulation promulgated thereunder or pursuant thereto, reference is made to the "Purchasing Officer," such reference shall be deemed to be to the "Director of Purchasing" as if the same had been originally placed or substituted therefor in such provision.
