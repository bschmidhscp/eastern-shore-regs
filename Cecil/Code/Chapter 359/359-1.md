# § 359-1. Statutory references.

*[Amended 11-13-2012 by Ord. No. 2012-12 ]*

For state law as to vehicles and traffic generally, see Annotated Code of Maryland, Transportation Article, §§ 11-101 to 27-114. As to rules of the road generally, see Annotated Code of Maryland, Transportation Article, §§ 21-101 to 21-1414. As to statewide application of Maryland vehicle law, see Annotated Code of Maryland, Transportation Article, § 25-101.1. As to powers of local authorities generally, see Annotated Code of Maryland, Transportation Article, § 25-102. As to placement of traffic-control devices generally, see Annotated Code of Maryland, Transportation Article, §§ 25-105 to 25-109.
