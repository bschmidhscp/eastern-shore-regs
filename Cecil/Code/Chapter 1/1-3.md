# § 1-3. Changes in previously adopted legislation.

A. In compiling and preparing the ordinances and public local laws for adoption and revision as part of the Code, certain grammatical changes and other changes were made in one or more of said ordinances and public local laws. It is the intention of the governing body that all such changes be adopted as part of the Code as if the ordinances and public local laws so changed had been previously amended to read as such.

B. In addition, the changes, amendments or revisions set forth in Schedule A, attached hereto and made a part hereof, are made herewith, to become effective upon the effective date of this ordinance as set forth in § 1-4 below. (Chapter and section number references are to the ordinances and public local laws as they have been renumbered and appear in the Code.)[1]

> Note: [1] Editor’s Note: In accordance with § 1-3B , the chapters, parts and sections which were added, amended, adopted or deleted by this ordinance are indicated throughout the Code by the following history: “Amended (added, repealed) 11-13-2012 by Ord. No. 2012-12." Schedule A, which contains a complete description of all changes, is on file in the County offices.
