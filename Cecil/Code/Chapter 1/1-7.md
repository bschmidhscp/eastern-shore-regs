# § 1-7. Code to be kept up-to-date.

It shall be the duty of the Director of Administration, or someone authorized and directed by the County Executive, to keep up-to-date the certified copy of the book containing the Code required to be filed in the Director of Administration's office for the use of the public. All changes in said Code and all ordinances adopted subsequent to the effective date of this codification which shall be adopted specifically as part of the Code shall, when finally adopted, be included therein by reference until such changes or new ordinances are published as supplements to said Code.
