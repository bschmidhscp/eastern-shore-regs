# § 1-5. Copy of Code on file.

A copy of the Code in loose-leaf or post binder form shall remain on file in the Director of Administration’s office, to be made available to persons desiring to examine the same during all times while the Code is in effect. Such copy shall be certified to by the Clerk of Cecil County by impressing thereon the Seal of the County.
