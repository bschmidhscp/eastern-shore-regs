# § 64-30. Manner of collection of amounts owed to County.

When an owner of property is responsible to the County for the payment of money, the amount shall be levied, collected, and enforced in the same manner as County real property taxes and have the same priority rights, bear the same interest and penalties, constitute a lien on the real property so assessed, and be treated the same as County real property taxes.
