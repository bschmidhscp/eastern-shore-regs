# § 190-5. Zoning districts established.

5.1 Purpose. Article II establishes the Official Zoning Map that divides the County into zoning districts; establishes the purpose and requirements for each of the County's base zoning districts; and provides dimensional standards and bulk requirements that apply within all zoning districts.

5.2 Zoning districts listed.

  A. The base zoning districts listed in Table II-1 are hereby established to provide land use regulations throughout Talbot County:
