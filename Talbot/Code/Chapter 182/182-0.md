# § 182-0. Definitions.

As used in this chapter, the following definitions apply:

**ACTIVE VOLUNTEER MEMBER** A person who has accumulated a minimum of 50 points per calendar year, in accordance with the point system set forth in this chapter.

**DIRECTOR** The Director of Emergency Services for Talbot County.
