# SECTION 164-11.0. Severability

The parts and subparts of this chapter are intended to be severable. If any court of competent jurisdiction should determine by a valid and final judgment that any part of this chapter, or the application thereof to any person or circumstance, is unconstitutional, illegal, or void for any reason, then notwithstanding that determination, the remaining provisions hereof and the application thereof to all other persons and circumstances shall remain in full force and effect.
