# § 12-1. Terms defined.

As used in this chapter, the following definitions shall have the meanings indicated:

**BOARD** The Queen Anne's County Plumbing Board.

**PLUMBING CODE** The Plumbing Code approved by the Maryland State Board of Plumbing.
