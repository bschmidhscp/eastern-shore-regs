# **`COUNTY ORDINANCE NO. 04-13`** 

# **`A BILL ENTITLED`** 

```
AN ACT CONCERNING the Specific Inclusion of Large-lot
Subdivisions as a Permitted use in Certain Zoning Districts under
Title 18 of the Code of Public Local Laws of Queen Anne’s County
(1996 Ed.);
```

```
FOR THE PURPOSE of providing for Large-lot subdivision as a
permitted use in certain zoning districts in Queen Anne’s County
(1996 Ed.);
```

```
BY AMENDING Sections 18-1-15,1 18-1-16, 18-1-17, 18-1-18,
18-1-19, 18-1-25, 18-1-28, 18-1-31, 18-1-32 and 18-1-33 of Title
18 of the Code of Public Local Laws of Queen Anne’s County (1996
Ed.).
```

# **`SECTION I`** 

```
BE IT ENACTED BY THE COUNTY COMMISSIONERS OF QUEEN ANNE'S
COUNTY, MARYLAND that Sections 18-1-15, 18-1-16, 18-1-17, 18-1-
18, 18-1-19, 18-1-25, 18-1-28, 18-1-31, 18-1-32 and 18-1-33 be
amended adding Large-lot subdivision as a permitted use, such
Sections to read as follows:
```
