# **`A BILL ENTITLED`** 

```
AN ACT CONCERNING Correction of a Typographical Error in
'18:1-76 of the Code of Public Local Laws of Queen Anne's
County, Maryland (1996 Ed.) ("the Code").
```

```
FOR THE PURPOSE of correcting a typographical error in
the Table of Street Buffers contained in '18:1-76 of the Code.
```

```
COUNTY, MARYLAND that the Table of Street Buffers contained in
'18:1-76 of the Code be amended to read as follows:

buffers.
```
