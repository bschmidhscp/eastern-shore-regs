# **`COUNTY ORDINANCE NO. 04-12`** 

# **`A BILL ENTITLED`** 

```
AN ACT CONCERNING Calculation of Density/Intensity
Requirements in Large Lot Subdivisions under Title 18 of the Code
of Public Local Laws of Queen Anne’s County (1996 Ed.);
```

```
FOR THE PURPOSE of clarifying that the total site area is to
be used in calculating density/intensity requirements for Large
Lot subdivisions under Title 18 of the Code of Public Local Laws;
```

```
BY AMENDING Section 18-1-14(d), 18-1-15(d), 18-1-16(d), 18-
1-17(d), 18-1-18(D), 18-1-19(d), 18-1-25(d), 18-1-28(d), 18-1-
31(d), 18-1-32(d) and 18-1-33(d) of the of the Code of Public
Local Laws of Queen Anne’s County (1996 Ed.).
```
