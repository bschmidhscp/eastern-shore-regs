# 2023

<!-- page 1 -->
```
COUNTY ORDINANCE NO. 05-20
```

```
A BILL ENTITLED
```

```
AN ACT CONCERNING the Repeal of Provisions Regarding
Electric Transmission Lines in Queen Anne's County;
```

```
FOR THE PURPOSE of repealing the regulations pertaining to
electric transmission lines contained in Section 18:1-58.I. of
Chapter 18 of the Code of Public Local Laws of Queen Anne's
County, Maryland.
```

```
BY Repealing Section 18:1-58.I. of Chapter 18 and
redesignating Section 18:1-58.J. to 18:1-58.I.
```

# **<u>`SECTION I`</u>** 

```
BE IT ENACTED BY THE COUNTY COMMISSIONERS OF QUEEN ANNE'S
COUNTY, MARYLAND, that Section 18:1-58.I of the Code of Public
Local Laws of Queen Anne's County, Maryland be and is hereby
REPEALED.
```

# **<u>`SECTION II`</u>** 

```
BE IT FURTHER ENACTED that Section 18:1-58.J. be
redesignated as 18:1-58.I. of the Code of Public Local Laws.
```

# **<u>`SECTION III`</u>** 

```
BE IT FURTHER ENACTED that upon introduction, this Bill
shall be referred to the Queen Anne's County Planning Commission
for review and recommendation.
```

# **<u>`SECTION IV`</u>** 

```
BE IT FURTHER ENACTED that this Ordinance shall be effective
on the forty-sixth day following its passage.
```
