# **`COUNTY ORDINANCE NO. __04-40______`** 

```
A BILL ENTITLED
```

```
AN ACT CONCERNING An Amendment to Chapter 24 of the Code
of Public Local Laws of Queen Anne's County (1996 Ed.)
Concerning the Authority of the Queen Anne's County Sanitary
District Over Land Annexed By a Municipality;
```

```
FOR THE PURPOSE of deleting the restrictions in the Code
of Public Local Laws on authority of the Queen Anne's County
Sanitary District over land annexed by a municipality;
```

```
BY AMENDING Section 24-1 of Chapter 24 of the Code of
Public Local Laws of Queen Anne's County (1996 Ed.).
```

# **`SECTION I`** 

```
BE IT ENACTED BY THE COUNTY COMMISSIONERS OF QUEEN ANNE'S
COUNTY, MARYLAND that Section 24-1 of Chapter 24 of the Code
of Public Local Laws of Queen Anne's County, Maryland (1996
Ed.) be amended to read as set forth on Exhibit A.
```

# **`SECTION II`** 

```
BE IT FURTHER ENACTED that this Bill shall take effect on
the forty-sixth day following its enactment.
```

# **`SECTION III`** 

```
BE IT FURTHER ENACTED that this Ordinance shall be
effective on the forty-sixth day following its passage.
```
