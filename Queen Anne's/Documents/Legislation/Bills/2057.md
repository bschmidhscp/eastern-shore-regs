# **`COUNTY ORDINANCE NO. 04-18`** 

# **`A BILL ENTITLED`** 

```
AN ACT CONCERNING Landscaping Requirements in the Town
Center (TC) District;
```

```
FOR THE PURPOSE of providing landscaping requirements to the
Town Center (TC) District under Title 18 of the Code of Public
Local Laws of Queen Anne’s County (1996 Ed.) (hereafter “the
Code”);
```

```
BY AMENDING a new subsection (g) to Section 18-1-28 of the
Code.
```

# **`SECTION I`** 

```
BE IT ENACTED BY THE COUNTY COMMISSIONERS OF QUEEN ANNE'S
COUNTY, MARYLAND that a new Subsection 18-1-28(g) be added to
Section 18-1-28 of the Code to read as follows:
```

```
§18-1-28 Town Center (TC) District.
```

```
 (g) Landscaping requirements
```

```
(1) The number of plantings required in the TC District
shall be consistent with the number of plantings
required in the UC District.
```

```
(2) The location of required plantings can be adjusted
to accomplish the TC Design Guidelines.
```

```
(3) To accomplish the Design Guidelines additional
landscaping may be necessary.
```

# **<u>`SECTION II`</u>** 

```
BE IT FURTHER ENACTED that this Ordinance shall be effective
on the forty-sixth day following its passage.
```
