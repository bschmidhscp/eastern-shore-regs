# **`COUNTY ORDINANCE NO. 04-35`** 

```
A BILL ENTITLED
```

```
AN ACT CONCERNING the Adoption of a new Queen Anne's
County Sectional Zoning Map No. 58A.
```

```
FOR THE PURPOSE of correcting the scale and dimensions of
the official Queen Anne's County Zoning Map No. 58A.
```

```
BY REPEALING existing official Queen Anne's County Zoning
Map No. 58A and adopting the new Sectional Zoning Map No. 58A
as one of the official zoning maps for Queen Anne's County.
```

# **<u>`SECTION I`</u>** 

```
Official Queen Anne's County Zoning Map No. 58A be and is
hereby repealed and the attached new Queen Anne's County
Sectional Zoning Map No. 58A be and is hereby adopted as one
of the official zoning maps for Queen Anne's County, Maryland.
```

# **<u>`SECTION II`</u>** 

```
BE IT FURTHER ENACTED that this Ordinance shall be
effective on the forty-sixth day following its passage.
```
