# **`AN AMENDMENT TO COUNTY ORDINANCE NO. 05-26`** 

# **`AN AMENDMENT TO A BILL ENTITLED`** 

```
AN ACT CONCERNING Amendments to §18:1-7 of the Code of
Public Local Laws of Queen Anne's County to Provide that
Completed Applications for Major Subdivision Approval shall be
Processed and Recorded in accordance with the Zoning Ordinance in
effect on the date the matter was filed if such application has
received Staff Technical Advisory Committee review.
```

```
FOR THE PURPOSE of amending pending County Ordinance 05-26
to provide that completed applications for major subdivision
approval, if such application has received preliminary approval
by the Queen Anne's County Planning Commission, shall be
processed and/or decided in accordance with the Ordinance in
effect on the date on which such application was filed.
```

```
BY AMENDING pending County Ordinance 05-26 to remove the
reference to Staff Technical Advisory Committee Review and
provide for Planning Commission preliminary approval.
```

# **<u>`SECTION I`</u>** 

```
BE IT ENACTED BY THE COUNTY COMMISSIONERS OF QUEEN ANNE'S
COUNTY, MARYLAND that Section 18:1-7.C. of the Code of Public
Local Laws of Queen Anne's County be and is hereby repealed and
reenacted to read as follows:
```
