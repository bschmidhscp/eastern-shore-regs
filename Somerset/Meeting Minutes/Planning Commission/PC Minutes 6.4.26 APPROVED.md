Ms. Catherine Skeeter shared a summary of the status of the FY2027 MALPF round, describing the process of ranking, upcoming Ag Board and County Commission approvals, and submittal to the State by July 1st. ## **C** . **Draft Text Amendments to the Somerset County Zoning Code** 

Mr. Will Cornish provided a summary of the proposed Zoning Code changes. Mr. Andrew Illuminati asked what the logic behind limiting Retreats to already-improved parcels was.  Mr. Drewer shared that this language was drawn exactly from that which exists in the corresponding recently-crafted Critical Area code for Retreats, but that is does seem to unnecessarily restrict retreats in the zoning code for non-Critical Area properties.  Staff and Planning Commission members agreed that this should be fixed. 

Mr. Webster asked about the new Accessory Dwelling Unit language and whether any singlefamily home, even a single wide, could have an ADU on site.  Mr. Cornish shared that yes, even a lot with a single wide would be eligible for an ADU, assuming all other regulations are met.  Mr. Colborn asked about restrictions to the implementation of this new ADU language due to utility availability, such as well and septic.  Staff commented that the Health Department’s well and septic requirements will still dictate whether dwelling units will be permissible. 

Mr. Drewer shared that the Planning Commission should expect to see these Zoning Code Text Amendments on next month’s July 9<sup>th</sup> agenda for a Public Hearing. 

Mr. Colborn asked if annual amendments to the code were on a typical schedule.  Staff shared that it is quite normal for text amendments to be needed following the State’s Legislative Cycle, and that additional housekeeping items are regularly lumped into this process.  Staff encouraged Planning Commission members to inform them of any suggested code amendments for consideration in the next amendment.
